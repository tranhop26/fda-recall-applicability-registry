# GitHub CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reproducible, secret-free GitHub Actions quality gate that never deploys or sends a Studionet transaction.

**Architecture:** One policy test locks down the workflow's required checks and forbidden write-capable behavior. One GitHub Actions workflow runs the same non-live quality gates on Ubuntu with Python 3.12 for pushes and pull requests to `master`.

**Tech Stack:** GitHub Actions, YAML, Python 3.12, pytest, Ruff, GenVM linter, jsonschema

## Global Constraints

- Do not load wallet credentials, call contract write methods, run the `studionet` marker, deploy, publish, or modify repository contents.
- Trigger only on pushes to `master`, pull requests targeting `master`, and optional manual dispatch.
- Grant `contents: read` and no broader GitHub token permission.
- Use the pinned dependencies in `requirements.txt`.
- Keep the existing deployment manifest as evidence; do not regenerate it in CI.

- [ ] **Step 1: Write the failing policy test**

```python
from pathlib import Path


WORKFLOW = Path(".github/workflows/ci.yml")


def test_ci_is_secret_free_and_covers_required_quality_gates():
    text = WORKFLOW.read_text(encoding="utf-8")
    required = (
        "permissions:\n  contents: read",
        "python-version: '3.12'",
        "python -m pip check",
        "genvm-lint check contracts/fda_recall_applicability_registry.py",
        "python -m ruff format --check .",
        "python -m ruff check .",
        "python -m pytest -m \"not integration and not studionet\" -q",
        "python -m pytest tests/integration --collect-only -q",
        "python -m jsonschema -i deployments/studionet.json deployments/manifest.schema.json",
        "python -m jsonschema -i verification/test-summary.json verification/test-summary.schema.json",
    )
    for token in required:
        assert token in text
    lowered = text.lower()
    for forbidden in ("private_key", "mnemonic", "run_studionet=1", "gh release", "genlayer deploy"):
        assert forbidden not in lowered
```

- [ ] **Step 3: Add the minimal workflow**

```yaml
name: CI

on:
  push:
    branches: [master]
  pull_request:
    branches: [master]
  workflow_dispatch:

permissions:
  contents: read

jobs:
  quality:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - name: Install pinned dependencies
        run: python -m pip install --requirement requirements.txt
      - name: Validate dependencies
        run: python -m pip check
      - name: Validate GenLayer contract
        env:
          PYTHONUTF8: '1'
        run: genvm-lint check contracts/fda_recall_applicability_registry.py
      - name: Check formatting
        run: python -m ruff format --check .
      - name: Lint Python
        run: python -m ruff check .
      - name: Run non-live tests
        run: python -m pytest -m "not integration and not studionet" -q
      - name: Collect live integration test
        run: python -m pytest tests/integration --collect-only -q
      - name: Validate deployment manifest
        run: python -m jsonschema -i deployments/studionet.json deployments/manifest.schema.json
      - name: Validate test evidence
        run: python -m jsonschema -i verification/test-summary.json verification/test-summary.schema.json
```
