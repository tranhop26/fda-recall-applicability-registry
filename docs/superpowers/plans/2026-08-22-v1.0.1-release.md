# v1.0.1 Verified Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish and independently verify a `v1.0.1` GitHub release containing the final CI-enabled source and the existing verified Studionet deployment manifest.

**Architecture:** Treat the final synchronized `master` commit as an immutable release candidate. Validate that commit locally and in GitHub Actions, package only Git-tracked files, publish an annotated tag plus two release assets, then download the assets and compare their SHA-256 digests. No contract, deployment, wallet, or chain state changes are part of this release.

**Tech Stack:** Git, GitHub CLI, PowerShell, Python 3.12, WSL Python, GenVM lint, Ruff, Pytest, JSON Schema, SHA-256

## Global Constraints

- Preserve `v1.0.0` at commit `7cf03c54e7cae76fc01f75f98bccf01378a7f517`.
- Do not redeploy the contract, send a transaction, request a wallet signature, or use a private key.
- Tag `v1.0.1` only after local checks and the GitHub Actions run for the exact release candidate both succeed.
- Package only files tracked by Git at the release commit.
- Exclude `.env`, credentials, private keys, caches, virtual environments, local outputs, and Git metadata.
- Treat `v1.0.1` as immutable after publication; corrections require a newer patch version.
- Publish the release as public, non-draft, and non-prerelease.

### Task 3: Build and Inspect Release Assets

**Files:**
- Create locally, ignored: `outputs/release/v1.0.1/fda-recall-applicability-registry-v1.0.1.zip`
- Create locally, ignored: `outputs/release/v1.0.1/studionet.json`

**Interfaces:**
- Consumes: `$releaseSha`, `$releaseDir`, and the verified tracked tree
- Produces: `$sourceZip`, `$manifestAsset`, `$sourceDigest`, and `$manifestDigest`

- [ ] **Step 1: Build the source ZIP directly from Git**

Run:

```powershell
$sourceZip = Join-Path $releaseDir 'fda-recall-applicability-registry-v1.0.1.zip'
$manifestAsset = Join-Path $releaseDir 'studionet.json'
git archive --format=zip --prefix='fda-recall-applicability-registry-v1.0.1/' --output="$sourceZip" $releaseSha
if ($LASTEXITCODE -ne 0) { throw 'git archive failed' }
Copy-Item -LiteralPath 'deployments/studionet.json' -Destination $manifestAsset
```

Expected: both assets exist and are non-empty.

- [ ] **Step 2: Reject prohibited archive paths**

Run:

```powershell
$archiveEntries = @(tar -tf $sourceZip)
$prohibited = $archiveEntries | Where-Object {
  $_ -match '(^|/)(\.git|\.env|\.venv|venv|__pycache__|\.pytest_cache|\.ruff_cache|outputs|artifacts)(/|$)' -or
  $_ -match '(?i)(private[_-]?key|seed[_-]?phrase|mnemonic)'
}
if ($prohibited) { $prohibited; throw 'prohibited release path detected' }
if (-not ($archiveEntries -match '/contracts/fda_recall_applicability_registry.py$')) { throw 'contract source missing from archive' }
if (-not ($archiveEntries -match '/\.github/workflows/ci.yml$')) { throw 'CI workflow missing from archive' }
```

Expected: no prohibited path is found; contract source and CI workflow are present.

- [ ] **Step 3: Verify the manifest asset is byte-identical and compute digests**

Run:

```powershell
$trackedManifestDigest = (Get-FileHash -Algorithm SHA256 'deployments/studionet.json').Hash.ToLowerInvariant()
$manifestDigest = (Get-FileHash -Algorithm SHA256 $manifestAsset).Hash.ToLowerInvariant()
if ($trackedManifestDigest -ne $manifestDigest) { throw 'manifest copy mismatch' }
$sourceDigest = (Get-FileHash -Algorithm SHA256 $sourceZip).Hash.ToLowerInvariant()
Write-Output "source_sha256=$sourceDigest"
Write-Output "manifest_sha256=$manifestDigest"
```

Expected: the manifest hashes match and both final digests are recorded for Task 4.

### Task 4: Create the Immutable Tag and GitHub Release

**Files:**

- Publish: `outputs/release/v1.0.1/studionet.json`

**Interfaces:**
- Consumes: `$releaseSha`, `$runId`, `$sourceDigest`, `$manifestDigest`, `$sourceZip`, and `$manifestAsset`
- Produces: remote tag `v1.0.1` and a public verified GitHub release

- [ ] **Step 1: Re-check all immutable publication preconditions**

Run:

```powershell
if ((git rev-parse HEAD).Trim() -ne $releaseSha) { throw 'HEAD changed after verification' }
if ((git ls-remote origin refs/heads/master).Split("`t")[0] -ne $releaseSha) { throw 'origin/master changed after verification' }

if ($ci.headSha -ne $releaseSha -or $ci.conclusion -ne 'success') { throw 'release CI evidence is not valid' }
```

Expected: all checks pass immediately before publication.

- [ ] **Step 2: Create and push the annotated tag**

Run:

```powershell

$publishedTag = (git ls-remote --tags origin 'refs/tags/v1.0.1^{}').Split("`t")[0]
if (-not $publishedTag) { $publishedTag = (git ls-remote --tags origin refs/tags/v1.0.1).Split("`t")[0] }
```

Expected: the peeled annotated tag resolves exactly to `$releaseSha`.
